# Tempore research

Market and product research for Tempore: what to build next, for whom, and why. Each study lives in its own folder, named `<topic>-<yyyy-mm>`, with the finished report at `report.md` and the working notes behind it in `notes/`.

## Conventions

- `report.md` is the synthesis to read and share. `notes/` holds the per-topic research it was written from, with a source URL for every claim.
- Vendor-sourced figures are marked `[vendor]` (or "vendor" in the citation). Claims seen only in search-result snippets are marked unverified.
- A study's folder is not rewritten once delivered. Follow-up work (for example, practitioner interviews that validate a study) goes in a new folder that links back to the one it builds on, or in a dated `validation/` subfolder of the original.
- Markdown only, no build step. Keep file names lowercase with hyphens.
